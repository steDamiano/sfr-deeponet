# Sound Field Reconstruction with an Attention-Based Deep Operator Network
This repository contains the code of the paper "_Sound Field Reconstruction with an Attention-Based Deep Operator Network_".

If you find this repository useful in your research, please cite our paper:

>S. Damiano and T. van Waterschoot, "Sound Field Reconstruction with an Attention-Based Deep Operator Network", in _Proc. 2026 European Signal Processing Conference (EUSIPCO2026)_, Bruges, Belgium, Sep. 2026.

## Dataset
The dataset used to train and evaluate the model was simulated using the Matlab code available at [sound-field-neural-network](https://github.com/francesclluis/sound-field-neural-network)
